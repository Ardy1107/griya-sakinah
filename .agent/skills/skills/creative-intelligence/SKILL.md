# Creative Intelligence Protocol

> **Purpose:** Make AI output CREATIVE, not just correct. Prevent template-following behavior.

## 🔴 Anti-Template Protocol (MANDATORY)

### BANNED Patterns

| ❌ NEVER Do This | ✅ Do This Instead |
|------------------|-------------------|
| Generic hero section with stock image | Unique layout with brand-specific visuals |
| Standard navbar (logo left, links right) | Context-aware navigation for user persona |
| Basic card grid layout | Dynamic layout based on content type |
| Generic color scheme (blue/white) | Palette derived from brand identity |
| Cookie-cutter dashboard | Data-driven layout based on actual KPIs |
| Placeholder "Lorem ipsum" text | Real content or realistic mockup text |

### Before ANY UI Decision, Ask:

1. "Have I seen this exact layout on 100 other sites?" → If YES, **redesign**
2. "Does this design SURPRISE the user (positively)?" → If NO, **add creative element**
3. "Would this win a design award?" → If NO, **elevate quality**

## 🎨 Inspiration Patterns

### Layout Innovation Techniques

| Technique | When to Use | Example |
|-----------|-------------|---------|
| **Bento Grid** | Dashboard, feature showcase | Uneven grid with mixed sizes |
| **Scroll Storytelling** | Landing page, onboarding | Content reveals as user scrolls |
| **Glassmorphism** | Cards, modals, overlays | Frosted glass effect with blur |
| **Neumorphism** | Buttons, inputs (subtle) | Soft shadow, pressed effect |
| **Asymmetric Layout** | Hero sections, about pages | Break the grid intentionally |
| **Micro-interactions** | Buttons, toggles, navigation | Subtle animations on interact |
| **Dark Mode Excellence** | Entire app | Not just inverted colors — designed |
| **Data Visualization** | Charts, stats displays | Custom SVG, animated charts |

### Color Psychology

| Emotion | Colors | Use For |
|---------|--------|---------|
| Trust & Security | Deep blue, teal | Government, finance, auth |
| Energy & Action | Coral, orange, amber | CTAs, notifications, alerts |
| Growth & Success | Emerald, sage | Confirmations, positive states |
| Premium & Elegance | Slate, charcoal, gold | Admin panels, executive views |
| Calm & Focus | Sky blue, lavender haze | Reading, forms, inputs |

## 📊 Innovation Scoring

After every UI implementation, score:

| Criterion | Score (1-10) | Question to Ask |
|-----------|:----------:|-----------------|
| **Originality** | ? | "Is this notably different from standard templates?" |
| **Wow Factor** | ? | "Would user say 'wow' on first visit?" |
| **Intentional Design** | ? | "Can I explain WHY every design choice was made?" |
| **Micro-Details** | ? | "Are there delightful small details (animations, transitions)?" |
| **Consistency** | ? | "Does it feel like ONE designer made the whole app?" |

> **Target: Average ≥ 7/10.** If below 7, iterate on design before submitting.

## 🎯 Creative Enhancement Rules

```
FOR EVERY UI task:
1. Generate 2-3 design concepts MENTALLY before coding
2. Pick the MOST creative one (not the easiest)
3. Add at least 1 unexpected delight element
4. Verify against Anti-Template Protocol
5. Score using Innovation Scoring

FOR EVERY component:
1. Custom hover states (not just opacity change)
2. Meaningful transitions (ease-out, spring, not linear)
3. Responsive with DIFFERENT layouts per breakpoint (not just shrink)
4. Dark mode as FIRST-CLASS design (not afterthought)
```
