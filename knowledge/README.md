# 🧠 Knowledge Base — Super AI Level 99

> **Purpose:** General learnings yang berlaku di semua project. AI baca ini untuk jadi lebih pintar.

## Folder Structure

| Folder | Isi | Contoh |
|--------|-----|--------|
| `tech/` | Learnings tentang teknologi, framework, library | React 19 patterns, Next.js 15 changes |
| `research/` | Hasil riset internet (Google, YouTube, docs) | Best practices dari official docs |
| `solutions/` | Solusi proven untuk masalah umum | Fix untuk common errors |
| `ground-truth/` | Fakta terkunci — anti-hallucination | Confirmed API endpoints, library versions |

## Rules

1. **Semua model WAJIB baca** `ground-truth/` sebelum mulai kerja
2. **Setiap riset internet** hasilnya disimpan di `research/` → supaya gak riset ulang
3. **Format file:** Markdown, ringkas, actionable
4. **Naming:** `{topic}-{date}.md` (contoh: `nextjs15-migration-2026-03.md`)
